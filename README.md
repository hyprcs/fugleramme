# Twenty Australian historical birds for Fugleramme

Review material for twenty proposed Classic additions. The application pull request contains only twenty WebP images, the manifest and attribution. This separate branch holds previews and supporting evidence.

The birds are cut from original historical plates using conventional masking and resizing. Codex assisted research, preparation tools and checks; no bird pixels were generated or repainted. Physical-panel appearance has not been tested.

[Artist credits and terms](review/CREDITS.md) · [Per-bird provenance and qualifications](review/provenance.json) · [Source-rights records](review/evidence/source-rights/) · [Current local checks](review/evidence/final-tests.json)

The `review/` directory preserves the prepared review snapshot, including its then-unsent drafts and earlier validation records. Current pull request details are supplied in the PR itself. The wider Sydney collection and optional AI illustrations are excluded.
